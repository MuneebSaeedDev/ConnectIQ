# Workflow Documentation

The workflow is stateful through these documents:

- `figma/screen-inventory.md` — what exists in Figma and implementation status.
- `modules/module-plan.md` — ordered module roadmap.
- `modules/MOD-XXX.md` — detailed module specifications.
- `reviews/review-log.md` — automated review/test history.

The agent must update these documents after every audit, screen, module, review, or blocking event.
