## Backend Capabilities & Data Models
1. **Entities & Models**:
   - `Role` (`backend/src/models/roles/role.model.ts`): Organization-scoped roles with unique keys, privilege levels (`ADMINISTRATIVE`, `ELEVATED`, `STANDARD`, `RESTRICTED`, `READ_ONLY`), role types (`SYSTEM`, `CUSTOM`), and structured permissions.
   - `AccessControlSettings` (`backend/src/models/roles/accessControl.model.ts`): Organization-wide security policies covering Authentication Providers, MFA enforcement, Password Complexity, Session Lifecycles, and IP/Geo Access Restrictions.
2. **Services**:
   - `RbacService` (`backend/src/services/roles/rbac.service.ts`): Centralized business logic for role CRUD, system role immutability enforcement, permission matrix aggregation, and access policy updates.
3. **API Endpoints**:
   - `GET /api/organizations/:orgId/roles`: List roles with status/type/privilege filters and search.
   - `POST /api/organizations/:orgId/roles`: Create new custom role with validated permission schemas.
   - `GET /api/organizations/:orgId/roles/:roleId`: Get specific role details.
   - `GET /api/organizations/:orgId/roles/:roleId/edit`: Get role edit form baseline.
   - `PUT /api/organizations/:orgId/roles/:roleId`: Update role definition and permissions.
   - `DELETE /api/organizations/:orgId/roles/:roleId`: Delete custom role (with active-assignment safeguards).
   - `GET /api/organizations/:orgId/permission-matrix`: Organization-wide permission matrix overview.
   - `GET /api/organizations/:orgId/access-control`: Retrieve security access policies.
   - `PATCH /api/organizations/:orgId/access-control`: Update security access policies.
