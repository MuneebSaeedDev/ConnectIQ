## Backend Capabilities & Data Models
1. **Entities & Models**:
   - `User` (`backend/src/models/user.model.ts`): Stores user credentials (`passwordHash`), roles, status (`active`, `pending`, `suspended`, `deactivated`), email verification flag, 2FA settings, and organization scoping.
   - `RefreshToken` (`backend/src/models/token.model.ts`): Secure, server-tracked refresh token storage with expiration, IP/UserAgent tracking, and revocation support for refresh token rotation.
   - `PasswordResetToken` (`backend/src/models/token.model.ts`): Opaque 1-hour expiration tokens for single-use password reset links with anti-enumeration handling.
   - `EmailVerificationToken` (`backend/src/models/token.model.ts`): 24-hour expiration single-use tokens for confirming email addresses.
2. **Services & Utilities**:
   - `AuthService` (`backend/src/services/auth/auth.service.ts`): Centralized business logic for login, session revocation, token management, password resets, and 2FA handling.
   - `jwt.ts` (`backend/src/utils/jwt.ts`): Dual-token architecture with short-lived access tokens and longer-lived refresh tokens.
   - `password.ts` (`backend/src/utils/password.ts`): Bcrypt salted hashing and verification.
3. **API Endpoints**:
   - `POST /api/auth/login`: Authenticates credentials, tracks session, returns JWT access and refresh tokens.
   - `POST /api/auth/logout`: Revokes the provided refresh token and invalidates active session.
   - `POST /api/auth/forgot-password`: Issues a secure password reset token with anti-enumeration protections.
   - `POST /api/auth/reset-password`: Validates reset token, updates password, and revokes all active refresh tokens.
   - `POST /api/auth/change-password`: Authenticated endpoint to change password with current password verification.
   - `POST /api/auth/verify-email/resend`: Issues and sends an email verification token.
   - `POST /api/auth/verify-email/confirm`: Validates token and marks email address as verified.
   - `POST /api/auth/2fa/verify`: Validates 6-digit two-factor verification code.
   - `POST /api/auth/2fa/resend`: Dispatches new 2FA code.
   - `GET /api/health`: Platform health check.
4. **Middleware**:
   - `requireAuth` (`backend/src/middlewares/auth.middleware.ts`): Validates bearer token, active user status, and attaches authenticated token payload to incoming request.
