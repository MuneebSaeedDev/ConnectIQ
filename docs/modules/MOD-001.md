## Implemented Capabilities
1. **Application Shell (`AppShell.jsx`)**:
   - Composes Header, Sidebar, routed main content area, and Footer.
   - Handles collapsible sidebar state via Redux (`sessionSlice.js`).
   - Supports full-bleed canvas modes (for Visual Pipeline Builder) and standard padded scroll views.
2. **Top Navigation (`Header.jsx`)**:
   - Breadcrumb navigation supporting dynamic path segments and static arrays.
   - Global search input placeholder.
   - Live notification panel trigger button with unread count indicator.
   - User profile menu trigger button with user avatar and dropdown menu.
3. **Sidebar Navigation (`Sidebar.jsx`)**:
   - ConnectIQ logo branding with Meridian logomark asset.
   - Role-based navigation filtering via `useVisibleNav.js` and `permissions.js`.
   - Collapsible navigation groups with keyboard accessibility.
   - Live badge counters (e.g. error counts).
   - Sidebar toggle icon with directional flip.
4. **Footer (`Footer.jsx`)**:
   - Platform operational statistics (active pipelines, workers, queue depth, throughput).
   - Copyright notice.
5. **Splash Screen (`SplashScreen.jsx`)**:
   - Sequential system bootstrap lifecycle (loading config, checking connectivity, restoring session).
   - Visual progress bar and status indicator with fallback for missing backend.
   - Automatic routing to `/dashboard` (if active session exists) or `/login`.
   - Accessible hidden status live regions.
6. **Notification Panel (`NotificationPanel.jsx` / SCR-012)**:
   - Slide-over / overlay panel with category tabs (All, Unread, Alerts, System).
   - React Query integration with 30s refetch.
   - "Mark all as read" mutation with optimistic updates.
   - Focus trap and Escape key handling.
7. **User Profile Menu (`UserProfileMenu.jsx` / SCR-013)**:
   - Dropdown menu with user profile details, role label, and links to Settings, Help, and Logout.

## Downstream Contracts & Mock Boundaries
- `sessionSlice.js`: Provides `currentUser`, `role`, and `sidebarCollapsed`. Ready to receive real user session data upon login from MOD-002.
- `permissions.js`: Centralized `hasPermission` / `hasAnyPermission` RBAC helper. Ready for dynamic permissions from MOD-003.
- `bootstrap.api.js`: Performs real `/health` check with documented fallback when backend is offline.
- `router.jsx`: Wraps unbuilt module routes in `shellRoute()` with `RoutePlaceholder`.
