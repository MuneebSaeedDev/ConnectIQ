# Initiator — Plan Modules

Run the `module-planner` skill.

Use the current Figma screen inventory, project specification, existing architecture, and implementation evidence to split the application into small, coherent, dependency-aware modules.

Create a strict ordered build plan. Map every required frontend screen to its module and identify backend, data, integration, authorization, and acceptance requirements.

Do not implement any screen or module during this run.

Follow `docs/agent-rules.md` strictly.

When the plan is complete and documented, STOP.
